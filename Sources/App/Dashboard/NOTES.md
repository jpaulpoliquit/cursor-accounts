# Dashboard layout arena

Question: How should a tabbed CursorBar dashboard be structured so it matches cursor.com/@jpl and is not one scrolling page?

Three structurally different layouts were built:

- **A — Profile column.** Centered column, identity header, peach underline tabs.
- **B — Settings rail.** Left sidebar, brand bar, cards in the pane.
- **C — Inspector.** Segmented control, Accounts as list | detail.

Verdict: **A.** It is the only layout that reads as cursor.com/@jpl (20/semibold name, #141414 chrome, no boxed page). B and C are settings/IDE chrome.

Accounts on A is a Notion-style table. Connect sits top-right like Invite. Active is a badge after the name; revealed email is a second line. Table vs list is a trailing icon well. ⌘1 / ⌘2 / ⌘3 jump Accounts / Models / Usage.
